Canvas & shapes

createCanvas(w, h)Make the canvas. createCanvas(windowWidth, windowHeight) fills the window
resizeCanvas(w, h)Change the size (use it in windowResized)
background(...)Fill the whole canvas. Add alpha for trails
rect(x, y, w, h, [radius]) · squareRectangles. rectMode(CENTER) makes (x, y) the center
circle(x, y, d) · ellipse(x, y, w, h)Circles and ovals (x, y is the center)
line(x1, y1, x2, y2) · point(x, y)Lines and dots
triangle(...) · arc(x, y, w, h, a1, a2)Triangles and pie slices
beginShape(); vertex(x, y); endShape(CLOSE);Custom shapes, waveforms
text(str, x, y) · textSize(n) · textAlign(CENTER, CENTER) · textStyle(BOLD)Text

Color & style

fill(r, g, b, [a]) · noFill()Inside color
stroke(...) · noStroke() · strokeWeight(n)Outline
colorMode(HSB)Hue 0–360, saturation 0–100, brightness 0–100, alpha 0–1
fill('#ff6fae')Web colors work too
(hue + 180) % 360Opposite (complementary) hue, wrapping around the wheel
lerpColor(c1, c2, t)Blend between two colors

Transformations

push() … pop()Save, then restore, position, rotation and styles. Always use them in pairs
translate(x, y)Move the origin
rotate(angle)Rotate around the origin (radians: TWO_PI = full turn)
scale(s) · scale(1, -1)Grow or shrink · mirror

Math & motion

map(v, a1, b1, a2, b2, [true])Convert from one range to another (true clamps the result)
constrain(v, min, max)Keep a value within limits
lerp(a, b, t)Mix between a and b. x = lerp(x, target, 0.1) eases toward a target
random(min, max) · randomSeed(n)Random numbers · a repeatable random sequence
noise(x, [y], [z])Smooth randomness, 0–1. Step the input slowly (0.005–0.02)
sin(a) · cos(a)Waves from -1 to 1. A circle is (cx + r·cos a, cy + r·sin a)
dist(x1, y1, x2, y2)Distance between two points
floor · round · abs · min · max · powThe usual helpers
a % bRemainder, used for looping counters
frameCount · millis() · deltaTimeTime: frames, milliseconds since start, milliseconds since last frame

Input

mouseX, mouseY, mouseIsPressedMouse state
key, keyCode, keyIsPressed, keyIsDown(code)Keyboard state. Codes include LEFT_ARROW, UP_ARROW, ENTER; letter S is 83
fullscreen(true/false) · noCursor()Performance mode

Sound (p5.sound)

song = loadSound(url)In preload()
userStartAudio()Unlock audio. Call it in mousePressed (browser rule)
song.play() .loop() .pause() .stop() .isPlaying()Playback
song.currentTime() .duration() .jump(sec) .setVolume(v)Position and volume
amp = new p5.Amplitude() · amp.getLevel()Loudness, 0 to about 0.4
fft = new p5.FFT(smoothing, bins)Frequency analyzer (e.g. 0.8, 1024)
fft.analyze()Call once per frame. Returns the spectrum array (0–255)
fft.getEnergy('bass' | 'lowMid' | 'mid' | 'highMid' | 'treble')One band, 0–255. Or a custom range: getEnergy(40, 100)
fft.waveform()Waveform array, -1 to 1
bands = fft.getOctaveBands(3) · fft.logAverages(bands)Musical, log-spaced spectrum
mic = new p5.AudioIn(); mic.start(); fft.setInput(mic);Live input (mic or line-in)

Audio-reactive recipes

// punchy smoothing (attack / release)
v = target > v ? lerp(v, target, 0.6) : lerp(v, target, 0.1);

// auto-gain → 0..1
peak = max(peak * 0.995, raw, 30);   let n = raw / peak;

// beat detection
avg = lerp(avg, bass, 0.05);
if (bass > avg * 1.25 && bass > 60 && millis() - last > 250) { last = millis(); /* BEAT */ }

// kick envelope: set to 1 on beat, decays each frame
if (beat) kick = 1;   kick *= 0.88;

// edge detection (section change, drop)
if (now !== before) { /* changed! */ }   before = now;

// count bars and phrases
let bar = floor(beats / 4);   let phrase = floor(beats / 32);

Common errors

X is not definedTypo, wrong capitalization, or a missing let
Unexpected token / end of inputA bracket or comma is missing or extra
Nothing movesYou called background() in setup() but not draw(), or the variable is created inside draw(), so it resets every frame
No soundClick the output first. Check the track bar. Check the system volume
Keys don't workClick the output so it has focus
My function acts weirdIts name might clash with a p5 function (hue, norm, color…). Rename it
Everything is the same colorfill() stays set until you change it. Use push()/pop()
