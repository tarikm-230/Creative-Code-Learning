Loading and playing

Three new pieces:

  • preload() is a third special function. It runs before setup() and waits until files have finished loading.
  • loadSound(AUDIO_URL) loads the track. AUDIO_URL is a variable this site provides: it points to whatever you picked in the track bar. In your own projects it will point to your file.
  • Browsers block sound until the user clicks. That's an anti-annoying-ads rule. So we start playback in mousePressed() and call userStartAudio() to unlock audio.

Measuring loudness: p5.Amplitude

new p5.Amplitude() creates a loudness meter that listens to everything p5 is playing. amp.getLevel() gives the current volume as a number from 0 to 1.

Real music rarely goes above 0.4 So don't map from 0–1. Map from 0 to about 0.3, and use constrain or map(..., true) so loud peaks don't explode. Every track is different, which is why the sketch below shows the live number so you can calibrate.

Try this

  1. Watch the number. What's the loudest level you see? Change 0.3 in both map() calls to suit it.
  2. The size jumps around a lot. Try amp.smooth(0.9); in setup() (values from 0 to 0.99, higher is smoother). You'll learn a better smoothing method in lesson 09.
  3. Use loudness for something other than size: the strokeWeight, the number of shapes in a loop, or the background brightness.
  4. Load one of your DJ friend's tracks with the track bar and compare. Notice that the levels change.

Seeing a song's structure

Combine loudness with the history array from lesson 06 and you get a scrolling graph of the whole track. You can see the breakdown (the dip) and the drop (the wall). Knowing where those moments are is the key to Project 1.

Why DJs will love this Dance tracks follow strong structures: 8-, 16- and 32-bar phrases, with build-ups, breakdowns and drops. Visuals that change with the structure look intentional and "designed". Visuals that only pulse look like a screensaver. Keep this in mind for the projects.

Show one possible solution (the radial pattern, made reactive) 
let angle = 0;

function draw() {
  let level = amp.getLevel();
  background(260, 50, 8);
  translate(width / 2, height / 2);

  angle += map(level, 0, 0.3, 0.002, 0.04, true);     // louder = spins faster
  rotate(angle);

  let spokes = 24;
  let len = map(level, 0, 0.3, 60, 170, true);          // dramatic
  let hue = map(level, 0, 0.3, 280, 330, true);         // subtle
  for (let i = 0; i < spokes; i++) {
    push();
    rotate(TWO_PI * i / spokes);
    noStroke();
    fill(hue, 70, 100);
    rect(40, -3, len, 6, 3);
    pop();
  }
  fill(0, 0, 100);
  circle(0, 0, 30 + level * 200);
}
