Mouse and keyboard

There are two ways to read input:

  • Checking every frame, inside draw(): mouseIsPressed and keyIsPressed are true while a button or key is held down. Use these for things that last as long as you hold, like a strobe.
  • Event functions that p5 calls once per press: mousePressed() and keyPressed(). Inside keyPressed(), the variable key tells you which key was pressed. Use these for switches, like changing scenes.
Click the output first Keyboard input only reaches the sketch after you click on its output area, because that gives it "focus". This is true for every sketch on this site.

Toggles: switches that remember

A boolean variable is either true or false. flag = !flag flips it. That's how you build an on/off switch.

A new trick appeared in that sketch: when an if controls only one statement, you can leave out the curly braces, as in if (key === '1') mode = 1;. For arrow keys and other special keys, check keyCode instead of key.

map(): the most important function in this course

Audio-reactive visuals are mostly about turning one range of numbers into another. For example, loudness goes from 0 to 1, but you want a size from 50 to 400. Or the mouse goes from 0 to width, but you want a hue from 0 to 360.

map(value, inMin, inMax, outMin, outMax)

map(mouseX, 0, width, 0, 360)   // mouse position → hue
map(level, 0, 1, 50, 400)        // loudness → size (lesson 07!)

map() doesn't stop at the edges, so a value outside the input range gives a result outside the output range. Wrap it in constrain(value, min, max) to keep it inside, or pass true as a 6th argument to map().

🎛 Challenge: Mini VJ controller (20 min)

Build a sketch you could actually "play":

  • Space toggles a blackout (black screen) on and off. Hint: key === ' '
  • Keys 1–3 pick one of three color palettes (three different base hues)
  • The mouse's x position controls the size of the main shape, using map()
  • Each mouse click adds one extra ring around the shape, up to 10, then goes back to 0
Show one possible solution 
function draw() {
  background(0);
  if (blackout) return;   // "return" leaves draw() early: nothing else is drawn

  let size = map(mouseX, 0, width, 40, 300, true);
  background(base, 50, 15);
  noStroke();
  fill(base, 80, 100);
  circle(width / 2, height / 2, size);

  noFill();
  stroke((base + 180) % 360, 70, 100);
  strokeWeight(3);
  for (let i = 1; i <= rings; i++) {
    circle(width / 2, height / 2, size + i * 16);
  }
}

function keyPressed() {
  if (key === ' ') blackout = !blackout;
  if (key === '1') base = 200;
  if (key === '2') base = 320;
  if (key === '3') base = 40;
}

function mousePressed() {
  rings = rings + 1;
  if (rings > 10) rings = 0;
}
