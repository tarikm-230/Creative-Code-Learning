Scenes, Palettes & Going Live

So far, each sketch has been one idea. A live show needs several looks, a way to switch between them without stopping, live audio from the DJ mixer, and a full-screen output. This lesson gives you the structure that both projects are built on.

Fill the screen

function setup() {
  createCanvas(windowWidth, windowHeight);   // as big as the window
}

function windowResized() {                    // p5 calls this when the window changes size
  resizeCanvas(windowWidth, windowHeight);
}

function keyPressed() {
  if (key === 'f') fullscreen(!fullscreen()); // toggle fullscreen (needs a key press or click)
}

From now on, position everything relative to width and height (for example min(width, height) * 0.3 for a size) so your visual looks right on a laptop, a projector, or an LED wall with an unusual shape.

The structure of a show

When a sketch grows past about 100 lines, you need a structure. This one is used by professional tools and scales well:

  • The audio engine runs once per frame. It analyzes the sound and writes clean, 0–1 normalized values into one object, A.
  • Scenes are just functions that draw using A. They know nothing about FFTs, so writing a new scene is easy and every scene reacts in a consistent way.
  • Controls (keys) change the current scene, palette, blackout and so on.

Live input and auto-gain

new p5.AudioIn() listens to the computer's input. That's the built-in mic, or whatever is plugged into the line-in or an audio interface. Live levels are unpredictable: a quiet room, a loud club, a mixer turned up or down. Auto-gain fixes this. It remembers the recent peak of each band, which slowly decays, and divides by it. The result is that a value of 1 always means "as loud as it's been lately".

function autoGain(name, value) {
  peak[name] = max(peak[name] * 0.995, value, 30);  // slowly forget old peaks
  return value / peak[name];                         // → roughly 0..1
}

Adding a scene takes three steps

  1. Write a function, for example function sceneStars() { … }, that draws using A.bass, A.kick, palHue(0) and so on
  2. Add it to the list: { name: 'Stars', draw: sceneStars }
  3. Press 4

Each scene starts with a push() and ends with a pop() (handled in draw()), so a translate or rectMode in one scene can't break another.

Gig setup: getting the music into the laptop
  • Best: line-in from the mixer. Most DJ mixers have a Booth or Rec/Record out. Run a cable from it into a cheap USB audio interface (e.g. Behringer UCA202 or Focusrite Scarlett Solo), and select that interface as the computer's input. The signal is clean, with no crowd noise.
  • Good enough: the laptop mic. Thanks to auto-gain, the bass and beats will still work in a loud room. Highs will be noisier.
  • If the DJ plays from a laptop: you can't easily capture its audio on a different computer without a cable. Use the mixer out.
  • The browser asks for microphone permission the first time. Allow it, and pick the right device from the camera/mic icon in the address bar.
Performance checklist
  • Add pixelDensity(1) in setup(). On high-resolution (Retina or 4K) screens it can double your frame rate. Projectors don't need the extra pixels.
  • Watch frameRate(): print round(frameRate()) in the HUD. Stay above 50.
  • Cap particle counts. Lots of transparency plus thousands of shapes will slow things down.
  • Use Chrome, close other tabs, plug the laptop into power, and turn off sleep and notifications.
  • Projector: use extended display, drag the browser window onto it, then press F. Add noCursor() to hide the mouse.
  • Always know your blackout key. If something breaks, black is a valid VJ choice.

Show an example scene (starfield, driven by the music) 
let stars = [];

function sceneStars() {
  if (stars.length === 0) {
    for (let i = 0; i < 500; i++) stars.push({ x: random(-1, 1), y: random(-1, 1), z: random(1) });
  }
  background(0, 0, 0, 0.5);
  translate(width / 2, height / 2);
  let speed = 0.004 + A.bass * 0.02 + A.kick * 0.03;   // kicks = warp jumps
  noStroke();
  for (let s of stars) {
    s.z -= speed;
    if (s.z <= 0.01) { s.x = random(-1, 1); s.y = random(-1, 1); s.z = 1; }
    let sx = s.x / s.z * width * 0.5;
    let sy = s.y / s.z * height * 0.5;
    fill(palHue(floor(abs(s.x) * 3)), 40, 100);
    circle(sx, sy, (1 - s.z) * 6 * (1 + A.treble));
  }
}
