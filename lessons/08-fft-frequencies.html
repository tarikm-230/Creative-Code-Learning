Frequencies: FFT & Waveforms

Loudness treats the whole track as one number. But the kick, the bassline, the vocal and the hi-hats all live in different frequencies. If you separate them, each one can drive its own part of the visual.

You will learn

  • What an FFT is (no math, promise)
  • How to draw a spectrum: fft.analyze()
  • How to get the five named bands: fft.getEnergy('bass') … 'treble'
  • How to draw the waveform (oscilloscope): fft.waveform()
  • How to make spectrum displays that look musical, using log-spaced bands

The idea

Any sound is a mix of many pitches at once. An FFT (Fast Fourier Transform) is like a prism for sound. It splits the mix into hundreds of thin slices, from low rumble to high sizzle, and tells you how loud each slice is right now.

The raw spectrum

Create the analyzer with fft = new p5.FFT(). Then, every frame, call fft.analyze(). It returns an array of 1024 numbers (each from 0 to 255), one per frequency slice, with bass first.

Notice that almost everything happens on the left side. That's because the slices are evenly spaced in Hz, but our ears hear pitch logarithmically: each octave doubles the frequency. So the musical "middle" is squeezed far to the left. We'll fix that below. First, here's the easy way to work with frequencies.

Named bands: getEnergy()

Usually you don't want 1024 numbers. You want "how much kick is there?" and "how much hi-hat?". fft.getEnergy('bass') returns 0–255 for that band. You can also ask for a custom range in Hz: fft.getEnergy(40, 100) isolates kick drums well.

Always call fft.analyze() first getEnergy() reads the result of the most recent analyze(). Call analyze() once at the top of draw(), then read as many bands as you like.

Try this

  1. Watch the demo beat. In the intro, only bass and treble move (kick and hats). In the groove, lowMid and highMid join (bassline and claps). In the breakdown, the bass goes quiet.
  2. Replace 'bass' with fft.getEnergy(40, 90). Does it pick out the kick more cleanly?
  3. Load a real track. Which bands are the busiest? Every genre has its own "fingerprint".

The waveform

fft.waveform() gives you the actual shape of the sound wave: an array of values from -1 to 1. Draw it as a line and you have an oscilloscope, the classic "music visualizer" look. It responds instantly and is very detailed, which makes it great for line-art styles.

Musical spectrums: log-spaced bands

To spread the spectrum the way ears hear it, group the slices into octave bands. fft.getOctaveBands(n) makes bands that are each 1/n of an octave wide, and fft.logAverages(bands) gives you one energy value per band. The result is about 30–60 values that are spread evenly across what you actually hear. That makes them ideal for radial and grid visuals.

Spectrum or bands: which do you need? Use getEnergy bands to control things: bass → scale, treble → sparkle, mid → color. Use the whole spectrum or waveform when you want to show the sound itself. Most good visuals do some of both.

🔊 Challenge: Speaker wall, for real (25 min)

Take your speaker wall from lesson 04 (or the reactive grid) and connect it to the music:

  • Each column reacts to a different band. With 5 columns, use the 5 named bands
  • The rings "pump" with the band's energy
  • Add a waveform line across the bottom, or around each speaker if you're feeling brave
  • Calibrate: bands that are rarely loud (like treble) may need a smaller input range, e.g. map(e, 0, 150, ...)
Show one possible solution 
function draw() {
  background(0, 0, 8);
  fft.analyze();
  let cols = BANDS.length, rows = 3;
  let cw = width / cols, ch = (height - 60) / rows;

  for (let c = 0; c < cols; c++) {
    let e = fft.getEnergy(BANDS[c]);
    let pump = map(e, 0, 255, 0.6, 1.5);
    for (let r = 0; r < rows; r++) {
      push();
      translate(c * cw + cw / 2, r * ch + ch / 2);
      noFill();
      stroke(c * 60 + 180, 60, map(e, 0, 255, 30, 100));
      strokeWeight(2);
      for (let k = 1; k <= 4; k++) circle(0, 0, k * 16 * pump);
      pop();
    }
  }

  let wave = fft.waveform();
  noFill();
  stroke(0, 0, 100);
  beginShape();
  for (let i = 0; i < wave.length; i += 4) {
    vertex(map(i, 0, wave.length, 0, width), height - 30 + wave[i] * 25);
  }
  endShape();
}
