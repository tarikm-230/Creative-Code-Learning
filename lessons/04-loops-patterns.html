Loops & Patterns

This is where creative coding pulls away from drawing by hand. One loop can draw a thousand shapes, and each one can be slightly different.

You will learn

  • How to use for loops to repeat with variation
  • How nested loops make grids
  • How translate, rotate, push and pop work, and how to use them to build radial patterns (mandalas, speaker cones, tunnels)
  • How to use dist() so every shape in a pattern can react on its own

The for loop

for (let i = 0; i < 10; i++) {
  // this runs 10 times, with i = 0, 1, 2 … 9
}

Read it as: "start i at 0. While i < 10, run the block, then add 1 to i (i++)." The magic is that you can use i inside the block to change the position, size or color of each copy.

Try this

  1. Change count to 40.
  2. Make the circles form a diagonal by also calculating a y from i.
  3. Make them bounce like an equalizer: let y = height / 2 + random(-50, 50);. (It flickers, and we'll tame that in lesson 05.)

Moving the grid itself: translate, rotate, push, pop

Up to now, (0, 0) has always been the top-left corner. translate(x, y) moves the origin, and rotate(angle) turns the whole coordinate system around that origin. Everything you draw afterwards is moved and turned too.

push() saves the current position, rotation and styles. pop() restores them. Always use them in pairs, so one shape's rotation doesn't leak into the next.

Angles are in radians: a full turn is TWO_PI (about 6.28), and half a turn is PI. If you prefer degrees, call angleMode(DEGREES) in setup().

Try this

  1. Change spokes to 6, then 60.
  2. Make every other spoke longer: let len = (i % 2 === 0) ? 140 : 80;, then use len as the rectangle's width. (a ? b : c is a one-line if: "if a, then b, otherwise c".)
  3. Add a second ring that spins the other way: put a new push(), rotate(-frameCount * 0.01), loop and pop() after the first loop.

Tunnels: loops plus scale

Draw the same shape many times, each one smaller and slightly rotated, and you get a tunnel. This trick turns up all over club visuals.

🔊 Challenge: Speaker wall (20 min)

Make a 4 × 3 grid of "speakers". Each speaker is a set of concentric circles (a loop inside the grid loops, so three loops deep!). Then:

  • The speaker closest to the mouse "pumps": its rings grow
  • Every speaker slowly rotates a little radial pattern in its center (use push, translate to the speaker's center, rotate, draw, pop)

You'll reuse this idea in the projects. Each speaker will end up reacting to a different frequency band.

Show one possible solution 
function draw() {
  background(0, 0, 8);
  let cols = 4, rows = 3;
  let cw = width / cols, ch = height / rows;

  for (let c = 0; c < cols; c++) {
    for (let r = 0; r < rows; r++) {
      let x = c * cw + cw / 2;
      let y = r * ch + ch / 2;
      let d = dist(x, y, mouseX, mouseY);
      let pump = map(d, 0, 150, 1.4, 1, true);

      push();
      translate(x, y);
      noFill();
      stroke(200, 40, 70);
      for (let k = 1; k <= 4; k++) {
        circle(0, 0, k * 18 * pump);
      }
      rotate(frameCount * 0.02);
      noStroke();
      fill(320, 70, 100);
      for (let s = 0; s < 6; s++) {
        rotate(TWO_PI / 6);
        rect(4, -2, 10, 4);
      }
      pop();
    }
  }
}
