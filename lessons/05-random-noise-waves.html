Randomness, Noise & Waves

Things that move with perfectly steady speed look like machines. Things that drift, wobble and breathe look alive. This lesson covers the three tools that make the difference.

You will learn

  • How random() works, and when it's the wrong tool
  • How noise() (Perlin noise) gives you smooth, organic randomness
  • How sin() and cos() make waves, pulses and orbits
  • How to draw custom shapes with beginShape() and vertex(), which you'll need for waveforms

random()

random(min, max) gives you a different number every time you call it. If you call it inside draw(), things flicker, because they get a new value 60 times a second. That's great for glitch and strobe effects, and bad for anything that should feel smooth.

A useful trick: randomSeed(42) makes the "random" numbers come out the same every frame (and every time you run the sketch). That gives you a stable random layout.

noise(): randomness with memory

noise(t) returns a value between 0 and 1. Unlike random(), nearby inputs give nearby outputs. If you slowly increase t, the value drifts smoothly up and down, like a hand-drawn line. This is the most-used function in generative art.

  • Move t by a small step each frame (0.005–0.02). Small steps give slow drift, big steps give a jittery wobble.
  • Use different "offsets", like noise(t) and noise(t + 1000), to get separate, independent wanderers.
  • 2D and 3D noise also exist: noise(x, y) and noise(x, y, t).

sin() and cos(): waves

sin(angle) moves smoothly between -1 and 1 as the angle grows. Feed it a growing number like frameCount * 0.05 and you get endless, perfectly even motion: breathing, swinging, pulsing. The recipe is always the same:

center + amplitude * sin(time * speed)

let size = 100 + 50 * sin(frameCount * 0.05);   // 50 … 150, breathing

cos() is the same wave, shifted. Using cos for x and sin for y moves a point around a circle:

x = cx + r * cos(angle);
y = cy + r * sin(angle);

Custom shapes: beginShape() and vertex()

To draw a shape that isn't a rectangle or circle, like a waveform or a blob, list its corners as vertices. Combine that with a loop and noise and you get organic forms:

Try this

  1. Change 60 * noise(...) to 150 * noise(...). The blob gets wilder.
  2. Change cos(a) + 1 to 2 * cos(a) + 1 (and the same for sin). This is "noise zoom": bigger numbers mean more bumps.
  3. Replace noFill/fill with noFill(); stroke(0, 0, 100); for a line-art look.

lerp(): easing toward a target

lerp(a, b, amount) finds a point between a and b. Its best use is this pattern, which you'll lean on heavily in lesson 09 to smooth jumpy audio values:

current = lerp(current, target, 0.1);  // move 10% of the way there, every frame

It creates natural ease-out motion: fast at first, then slowing as it arrives. lerpColor(c1, c2, amount) does the same for colors.

📈 Challenge: "Unknown Pleasures" (25 min)

Recreate the famous Joy Division album cover style: stacked horizontal lines, each one a wavy mountain range that moves over time.

  • Loop over about 30 rows. For each row, beginShape(), then loop x across the canvas and add vertex(x, y)
  • Each point's height comes from noise(x * 0.02, row * 0.3, t)
  • Make the bumps tallest in the middle of the canvas. Hint: multiply by something that's big at the center and small at the edges, like map(abs(x - width/2), 0, width/2, 1, 0)
  • Use fill(0) with a white stroke so each row hides the rows behind it

This is basically a 3D audio spectrogram. Later you can drive the height with real frequency data.

Show one possible solution 
function draw() {
  background(0);
  let t = frameCount * 0.01;
  stroke(255);
  strokeWeight(1.5);
  fill(0);

  for (let row = 0; row < 30; row++) {
    let baseY = 70 + row * 10;
    beginShape();
    for (let x = 40; x <= width - 40; x += 4) {
      let centerness = map(abs(x - width / 2), 0, width / 2 - 40, 1, 0);
      centerness = centerness * centerness;      // squared = sharper peak
      let h = noise(x * 0.02, row * 0.3, t) * 80 * centerness;
      vertex(x, baseY - h);
    }
    endShape();
  }
}
