Arrays, Objects & Particles

Confetti on the drop, sparks on every kick, stars rushing past: these are all particle systems. They're hundreds of little things, each with its own position and speed, that are born, move, fade and die. This is the last core coding lesson before sound.

You will learn

  • How to use arrays (lists): create, add with push, loop over, remove with splice
  • How to group related values into objects { x: 10, y: 20 }
  • How to write classes: a blueprint for making many similar objects
  • How to build a complete particle system

Arrays: lists of values

let sizes = [20, 45, 80];   // an array with 3 numbers
sizes[0]                    // → 20   (counting starts at 0!)
sizes.length                // → 3
sizes.push(120);            // add to the end → [20, 45, 80, 120]

for (let i = 0; i < sizes.length; i++) {
  circle(50 + i * 90, 200, sizes[i]);
}

Classes: blueprints for things

A particle needs a position, a velocity, a color and a lifespan, plus behavior: move, draw, and "am I dead?". A class bundles that data and behavior together. You write it once and create as many as you want with new.

class Particle {
  constructor(x, y) {      // runs when you write: new Particle(x, y)
    this.x = x;            // "this" = the particle being created
    this.y = y;
  }
  update() { this.y += 1; }        // a method: something it can do
  show()   { circle(this.x, this.y, 10); }
}

let p = new Particle(200, 50);
p.update();
p.show();

Hold the mouse down to emit particles. Each one gets a random direction, falls with gravity, and fades out over its life.

Why loop backwards? If you remove item 5 while looping forward, item 6 slides into position 5, and the loop moves on to 6, so it skips one. Looping from the end avoids that. Whenever you remove items from an array inside a loop, loop backwards.

Try this

  1. Set gravity to -0.05. Now it's smoke or fire, rising.
  2. Set gravity to 0 and friction to 0.95. Now it's an explosion that hangs in the air.
  3. Add an explode() burst: in mousePressed(), push 150 particles at once. A big burst like this is exactly what you'll trigger on beats in lesson 09.
  4. Watch the particle count. Performance matters for live visuals, so keep it under a few thousand.

Functions: name your own building blocks

You've been writing functions (setup, draw, keyPressed) and calling them (circle, map). You can make your own to keep big sketches organized. This will matter a lot when you build scenes for the projects:

function burst(x, y, count, hue) {
  for (let i = 0; i < count; i++) {
    particles.push(new Particle(x, y, hue));
  }
}

// later, anywhere:
burst(width / 2, height / 2, 200, 320);

A function can also give back a value with return, like isDead() above.

Don't reuse p5's names If you write function hue() or function norm(), p5 quietly replaces it with its own built-in function of the same name, and your sketch breaks in confusing ways. Pick names p5 doesn't use, like palHue or autoGain. The editor here warns you when this happens.

🎆 Challenge: Starfield / warp speed (25 min)

Build the classic "flying through space" effect. You'll reuse it as a scene in the Setlist Engine.

  • A Star class with x, y (random, from -width to width) and z (depth, from width down to 0)
  • Each frame, decrease z by a speed. When z < 1, reset the star to the far distance
  • Draw at screen position sx = x / z * width, sy = y / z * height (after translate to the center). This is perspective!
  • Closer stars are bigger: size = map(z, 0, width, 8, 0)
  • The mouse's x position controls the speed
Show one possible solution 
class Star {
  constructor() {
    this.reset();
    this.z = random(width);          // start at random depths
  }
  reset() {
    this.x = random(-width, width);
    this.y = random(-height, height);
    this.z = width;
  }
  update() {
    this.z -= speed;
    if (this.z < 1) this.reset();
  }
  show() {
    let sx = this.x / this.z * width;
    let sy = this.y / this.z * height;
    let size = map(this.z, 0, width, 8, 0);
    noStroke();
    fill(255);
    circle(sx, sy, size);
  }
}

function draw() {
  speed = map(mouseX, 0, width, 1, 40, true);
  background(0);
  translate(width / 2, height / 2);
  for (let s of stars) {     // "for...of" is a short way to loop over every item
    s.update();
    s.show();
  }
}
