Variables & Motion

A drawing becomes an animation when its numbers change over time. Variables are how you store those changing numbers.

You will learn

  • How to create and update variables with let
  • How draw() works as a 60-frames-per-second loop
  • How to use frameCount, % (remainder) and millis() for timing
  • How to make motion trails with a see-through background, a classic VJ look

Variables are labeled boxes

A variable is a name that holds a value. You create one with let:

let size = 80;        // create a box called "size" holding 80
size = size + 10;     // take what's in the box, add 10, put it back → 90
circle(200, 200, size);

Where you create the variable matters:

  • Create it at the top, outside any function, and it's a global: it keeps its value between frames. Use these for anything that changes over time, like position, speed or score.
  • Create it inside draw() and it's made fresh on every frame. Use these for temporary calculations.

Use const instead of let for values that never change, like const BPM = 120;.

Trails: the oldest trick in VJing

If you call background() with a transparent color, the previous frame doesn't fully disappear. Moving things leave ghostly trails. Lower alpha means longer trails.

Try this

  1. Change the background alpha from 20 to 5, then to 80.
  2. What does frameCount % 360 do? % gives the remainder: 361 % 360 = 1, so the number counts 0 → 359 and then starts over. That keeps the hue looping forever.

Timing to music: frames and beats

Now let's connect motion to music. At 60 frames per second and 120 BPM there are 2 beats per second, so a beat lasts 30 frames. frameCount % 30 counts 0 → 29 over and over, once per beat.

Frames aren't perfectly reliable, though, because a slow computer might only manage 45 fps. millis() is based on real time, so it's better for anything that has to stay in sync. One beat at a given BPM lasts 60000 / BPM milliseconds.

Look at 'beat ' + (beatNumber + 1). Text in quotes is called a string, and + joins strings with numbers. text(string, x, y) draws it on the canvas, which is useful for debugging. So is console.log(value), which prints to the console under the output.

⏱ Challenge: Four-on-the-floor (15 min)

Change the metronome so that:

  • There are 4 squares in a row, one per beat of the bar, and the current beat's square lights up
  • The whole background briefly flashes on beat 1
  • Bonus: change BPM to 128 (typical house tempo) and check that it still works

Hint: draw 4 squares at x = 50, 140, 230 and 320. For each one, use a bright fill if beatNumber matches its position and a dim fill if it doesn't. Copy-pasting four if blocks is completely fine for now. Lesson 04 will show you a shortcut.

Show one possible solution 
function draw() {
  let phase = (millis() % beatMs) / beatMs;
  let beatNumber = floor(millis() / beatMs) % 4;

  // flash on the one: bright at the start of beat 1, fading quickly
  if (beatNumber === 0) {
    background(255 * (1 - phase) * 0.6);
  } else {
    background(10);
  }

  noStroke();
  rectMode(CENTER);

  if (beatNumber === 0) { fill(255, 111, 174); } else { fill(50); }
  square(65, 200, 70);
  if (beatNumber === 1) { fill(124, 246, 200); } else { fill(50); }
  square(155, 200, 70);
  if (beatNumber === 2) { fill(124, 246, 200); } else { fill(50); }
  square(245, 200, 70);
  if (beatNumber === 3) { fill(124, 246, 200); } else { fill(50); }
  square(335, 200, 70);
}
