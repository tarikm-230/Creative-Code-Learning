Canvas, Shapes & Color

Every visual you'll ever make, including a full-screen drop explosion, is built from a few shapes drawn on a grid of pixels. This lesson teaches you that grid.

You will learn

  • How the canvas coordinate system works
  • How to draw shapes: rect, circle, ellipse, line, triangle, arc
  • How to style them: fill, stroke, strokeWeight, transparency
  • How to use HSB color, the easiest way to build color palettes

The coordinate system

createCanvas(400, 400) makes a canvas 400 pixels wide and 400 pixels tall. Every point on it has an x (how far from the left) and a y (how far from the top).

The one surprise In school math, y goes up. On screens, y goes down, so y = 0 is the top edge. Everyone gets caught by this at least once.

p5 gives you two handy built-in variables: width and height. The center of any canvas is always (width / 2, height / 2). Use them instead of typing numbers, and your sketch will still work when you go full-screen later.

Shapes

Each shape function takes numbers, called arguments, inside its brackets:

CodeDraws
rect(x, y, w, h)Rectangle. By default, (x, y) is its top-left corner
square(x, y, size)Square
circle(x, y, d)Circle. (x, y) is its center and d is its diameter
ellipse(x, y, w, h)Oval
line(x1, y1, x2, y2)Line between two points
triangle(x1, y1, x2, y2, x3, y3)Triangle with three corners
arc(x, y, w, h, start, stop)Slice of an ellipse. Angles are in radians: PI is half a turn
point(x, y)A single dot (its size comes from strokeWeight)

Try this

  1. Move the circle to the exact center of the canvas using width / 2 and height / 2.
  2. Add rectMode(CENTER); as the first line in draw(). What happens to the rectangle? Now (x, y) is its center, which is often easier to work with.
  3. Draw a smiley face with one circle, two smaller circles and an arc (try arc(200, 220, 120, 80, 0, PI)).

Color: fill, stroke and transparency

Style functions work like paint brushes you pick up. Once you call fill(), every shape after it uses that color until you change it again.

  • fill(r, g, b) sets the inside color. Each value goes from 0 to 255.
  • stroke(r, g, b) sets the outline color, and strokeWeight(n) sets its thickness.
  • noFill() and noStroke() turn them off.
  • Add a 4th number for alpha (opacity): fill(255, 0, 100, 120) is semi-transparent pink.
  • You can also use web colors: fill('#ff6fae') or fill('hotpink').

HSB: color the way artists think

RGB is how screens work, but it's hard to guess. (Quick: what's "a slightly darker orange" in RGB?) HSB describes color the way people do:

  • Hue: which color, as an angle around the color wheel from 0 to 360 (0 red, 120 green, 240 blue)
  • Saturation: how vivid it is, from 0 (gray) to 100 (pure)
  • Brightness: from 0 (black) to 100 (full)

Switch modes with colorMode(HSB). From then on fill(200, 80, 100) means "vivid, bright sky-blue". To get a darker version, lower the last number. To get a matching color, add 30 to the hue. HSB makes palettes easy, and later you'll drive hue from the music.

Why this matters for DJ visuals Club visuals usually look best with 2–3 related hues plus black, rather than a full rainbow. Pick a base hue for each track, then build everything from base, base + 30 and base + 180. You'll use this idea in the Setlist Engine.
Hue wraps around If base + 60 goes past 360, p5 limits it to 360 (red) instead of wrapping. Use (base + 60) % 360 to wrap it properly. % means "remainder after dividing", and you'll see it again in the next lesson.

🎨 Challenge: Cover art (15–20 min)

Design a 400×400 cover for a track your DJ friend plays, using only shapes and color. Requirements:

  • At least 6 shapes, using at least 3 different shape types
  • Use colorMode(HSB) and a palette built from one base hue
  • Use transparency at least once
  • Use width and height for at least the main element's position

Export it with ⤓ Export. This is a small, early portfolio piece, and you'll animate it later.

Show one possible solution 
function setup() {
  createCanvas(400, 400);
  colorMode(HSB);
}

function draw() {
  let base = 280;
  background(base, 60, 12);
  noStroke();

  // sun / record
  fill(base + 40, 70, 100);
  circle(width / 2, height / 2, 260);
  fill(base, 60, 12);
  circle(width / 2, height / 2, 40);

  // horizon stripes cutting through the sun
  fill(base, 60, 12);
  rect(0, 230, width, 8);
  rect(0, 255, width, 12);
  rect(0, 285, width, 16);

  // overlapping transparent triangles = mountains
  fill(base + 180, 60, 90, 0.6);  // in HSB, alpha goes 0–1
  triangle(0, 400, 120, 250, 260, 400);
  fill(base + 150, 60, 70, 0.6);
  triangle(140, 400, 300, 220, 400, 400);

  // title bar
  fill(0, 0, 100);
  rect(30, 30, 140, 6);
}

Note: in HSB mode, alpha goes from 0 to 1 instead of 0 to 255.
