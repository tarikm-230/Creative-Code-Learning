Why p5.js?

p5.js is a free JavaScript library made for artists, designers and beginners. Its add-on, p5.sound, can play audio files, listen to a microphone or line-in, and split music into bass, mids and highs. That's everything you need for music visuals, and it runs in any web browser, so there's nothing to install.

JavaScript is also a "real" language. What you learn here carries over to web development, to three.js for 3D, to Hydra for live-coded visuals, and to TouchDesigner's scripting.

The goal, in DJ terms By the end you'll have (1) a Song Portrait, a visual built for one track that follows its intro, build, drop and outro, and (2) a Setlist Engine, a full-screen visual app with a scene for each track. It runs from a file or a live line-in from the mixer, and you control it with the keyboard during the set.

Your first sketch

A p5.js program is called a sketch. Every sketch has two special functions:

  • setup() runs once when the sketch starts. You create the canvas here.
  • draw() runs over and over, about 60 times per second. Each run draws one frame of animation.

Try this (5 minutes)

  1. Change 80 to 200 and run it again. What changed?
  2. Change the three numbers in fill(124, 246, 200). These are red, green, blue, each from 0 to 255. Make the circle hot pink.
  3. Delete the line background(20, 20, 30); and run it. Why does it leave a trail? (Hint: background() wipes the canvas every frame.)
  4. Break something on purpose: change circle to circel. Read the error and the hint, then fix it.

Three rules of code

  1. Spelling and capitals matter. createCanvas works, createcanvas doesn't.
  2. Brackets come in pairs. Every ( needs a ) and every { needs a }. The editor highlights the matching bracket when your cursor is next to one.
  3. Code runs from top to bottom. Inside draw(), later shapes are painted on top of earlier ones, like layers.

Lines that start with // are comments. The computer ignores them, so use them to leave notes for yourself.
