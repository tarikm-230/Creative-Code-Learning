How to learn fast

Type, don't just read

Change every number you see. Break things on purpose. Reading code teaches you very little; changing it and seeing what happens teaches you a lot.

Timebox the challenges

Give each challenge its stated time. If you're stuck at the end, open the solution, understand it, and move on. The deadline matters more than perfection.

Keep your challenge code

Your edits are saved in this browser, and ⤓ Export saves any sketch as a file. Many challenges get reused as project scenes, and they make great process shots.

Get the music early

Ask your DJ friend now for 2–3 favorite tracks and a recent setlist. You'll need them for the projects.

Opening this site

Online (recommended)

Host it free on GitHub Pages: in the repository, go to Settings → Pages, set Source to "Deploy from a branch", pick the branch and the / (root) folder, and save. After a minute the site is live at https://<user>.github.io/<repo>/.

Offline

Everything is bundled: p5.js, p5.sound, the editor and the demo track. You can double-click index.html, or for the most reliable experience run a tiny local server in this folder:

python3 -m http.server 8000
# then open http://localhost:8000

Browser

Use Chrome or Edge on a laptop or desktop. Firefox and Safari mostly work, but the course was tested in Chrome. The editor isn't designed for phones.
