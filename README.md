# Creative Code in 48h

A progressive, project-based website for learning creative coding from zero. It's aimed at making **audio-reactive visuals for DJs** and finishing two portfolio projects in 48 hours.

- **Language:** JavaScript with [p5.js](https://p5js.org) and p5.sound
- **Format:** 12 lessons + 2 projects. Every code example is a live editor (edit → <kbd>Ctrl/Cmd+Enter</kbd> → see it run), with friendly error hints, auto-saved edits and one-click export
- **Projects:** *Song Portrait* (a generative visual for one track that follows its structure) and *Setlist Engine* (a live VJ instrument for a whole DJ set, with line-in/mic input, beat detection, tap tempo and keyboard performance controls)
- **Planner:** the home page turns the 48-hour plan into real clock times from your start time and fits it to the deadline (Oct 8, 12:00)

## Open it

**Online:** enable GitHub Pages (*Settings → Pages → Deploy from a branch → root*) and open `https://<user>.github.io/<repo>/`.

**Offline:** everything is bundled (libraries, editor, demo track), so you can double-click `index.html`. For the most reliable experience, especially microphone input, run a local server:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```

Use Chrome or Edge on a laptop or desktop.

## How the site works

```
index.html            home: progress, 48h planner, course map
lessons/*.html        lessons 00–11
projects/*.html       project briefs with starter code and milestone checklists
reference.html        cheat sheet
studio.html           blank sketchpad with templates
assets/playground.js  live editor: runs sketches in an iframe, console + error hints,
                      audio track picker, fullscreen, export to standalone HTML
assets/course.js      course data, navigation, progress, planner, countdown
assets/demo-audio.js  24 s demo beat (generated by tools/make-beat.js, no copyright)
vendor/               p5.js 1.11.13, p5.sound, CodeMirror 5 (bundled for offline use)
```

- Progress, checklists and code edits are stored in the browser's `localStorage`.
- **Export** creates a single self-contained HTML file with the libraries inlined. It runs offline from disk, and audio sketches get a start screen to pick a file or use mic/line-in. That's the file to bring to a gig.
- p5.sound normally fails on `file://` pages (its AudioWorklets load from `blob:` URLs). The playground and exports include a small shim that loads them from `data:` URLs instead.
- The editor warns you when a sketch declares a function whose name p5 already uses (e.g. `hue`, `norm`), because p5 silently overwrites it.
